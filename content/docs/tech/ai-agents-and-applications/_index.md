The book grows a program that starts with a single model call into document summarization, retrieval-based Q&A and tool-using agents. Following a web research engine and a travel assistant, these notes track how each approach's limits lead to the next design.

Each note starts from the chapter's core problem, connects concepts to code, and uses a small exercise to check what the design solves and what it leaves open. The overall arc and shared setup are in [Book overview](00-overview/). The notes are written in Korean.

Retrieval, agent and MCP operations continue in the [LLMOps guide](/docs/tech/ops/llmops/) for the fictional Bookway bookstore.
