[untools.co](https://untools.co/)가 모아 둔 사고 도구를 한국어로 다시 정리한 시리즈다. 원문을 옮기지 않고 도구마다 쓰임새, 쓰는 순서, 한계를 적고 IT 프로젝트와 클라우드 컨설팅 상황에 맞춘 예시를 하나씩 붙였다. 분류는 untools가 붙인 네 범주를 그대로 따르고, 범주마다 문서 하나로 묶었다.

| 도구 | 분류 | 언제 쓰나 | 문서 링크 |
| --- | --- | --- | --- |
| Iceberg Model(빙산 모델) | 시스템 사고 | 같은 사고가 반복되어 근본 구조를 찾을 때 | [01. 시스템 사고](/docs/business/thinking-tools/01-systems-thinking/#iceberg-model) |
| Connection circles(연결 원) | 시스템 사고 | 요소 사이 인과와 순환 고리를 그려 볼 때 | [01. 시스템 사고](/docs/business/thinking-tools/01-systems-thinking/#connection-circles) |
| Concept map(개념 지도) | 시스템 사고 | 낯선 시스템이나 개념을 구조로 이해할 때 | [01. 시스템 사고](/docs/business/thinking-tools/01-systems-thinking/#concept-map) |
| Reinforcing feedback loop(강화 피드백 루프) | 시스템 사고 | 문제가 눈덩이처럼 커지는 이유를 설명할 때 | [01. 시스템 사고](/docs/business/thinking-tools/01-systems-thinking/#reinforcing-feedback-loop) |
| Balancing feedback loop(균형 피드백 루프) | 시스템 사고 | 변화가 일정 수준에서 멈추거나 되돌아올 때 | [01. 시스템 사고](/docs/business/thinking-tools/01-systems-thinking/#balancing-feedback-loop) |
| Six Thinking Hats(여섯 색깔 모자) | 의사결정 | 회의에서 관점이 한쪽으로 쏠릴 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#six-thinking-hats) |
| Eisenhower Matrix(아이젠하워 매트릭스) | 의사결정 | 바쁜데 중요한 일이 진척되지 않을 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#eisenhower-matrix) |
| Impact-Effort Matrix(효과-노력 매트릭스) | 의사결정 | 할 일 목록에서 먼저 손댈 것을 고를 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#impact-effort-matrix) |
| Decision matrix(의사결정 매트릭스) | 의사결정 | 여러 기준으로 선택지를 비교할 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#decision-matrix) |
| Hard choice model(어려운 선택 모델) | 의사결정 | 결정에 들일 시간과 방식을 정할 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#hard-choice-model) |
| Second-order thinking(2차 사고) | 의사결정 | 당장 좋아 보이는 결정의 뒷결과를 볼 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#second-order-thinking) |
| Ladder of inference(추론의 사다리) | 의사결정 | 성급한 결론을 데이터로 되짚을 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#ladder-of-inference) |
| Cynefin framework(커네빈 프레임워크) | 의사결정 | 상황 종류에 맞는 대응 방식을 고를 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#cynefin-framework) |
| OODA loop(OODA 루프) | 의사결정 | 정보가 부족한 채 빠르게 움직여야 할 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#ooda-loop) |
| Confidence determines speed vs. quality(확신에 따른 속도와 품질) | 의사결정 | 속도와 품질 중 어디에 무게를 둘지 정할 때 | [02. 의사결정](/docs/business/thinking-tools/02-decision-making/#confidence-determines-speed-vs-quality) |
| Ishikawa Diagram(이시카와 다이어그램) | 문제 해결 | 원인 후보를 범주별로 빠짐없이 모을 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#ishikawa-diagram) |
| Issue trees(이슈 트리) | 문제 해결 | 큰 문제를 겹치지 않게 쪼갤 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#issue-trees) |
| First principles(제1원리 사고) | 문제 해결 | 관행이 된 전제를 걷어내고 다시 설계할 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#first-principles) |
| Inversion(역발상) | 문제 해결 | 실패 시나리오로 위험을 미리 찾을 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#inversion) |
| Abstraction laddering(추상화 사다리) | 문제 해결 | 요청 뒤에 있는 진짜 문제를 다시 정의할 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#abstraction-laddering) |
| Zwicky box(츠비키 박스) | 문제 해결 | 속성 조합으로 대안을 넓게 뽑을 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#zwicky-box) |
| Conflict Resolution Diagram(갈등 해소 다이어그램) | 문제 해결 | 두 주장이 정면으로 부딪칠 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#conflict-resolution-diagram) |
| Productive Thinking Model(생산적 사고 모델) | 문제 해결 | 정의된 문제를 실행 계획까지 끌고 갈 때 | [03. 문제 해결](/docs/business/thinking-tools/03-problem-solving/#productive-thinking-model) |
| Minto Pyramid(민토 피라미드) | 커뮤니케이션 | 보고와 메일을 결론부터 쓸 때 | [04. 커뮤니케이션](/docs/business/thinking-tools/04-communication/#minto-pyramid) |
| Situation-Behavior-Impact(SBI) | 커뮤니케이션 | 판단을 빼고 피드백을 전할 때 | [04. 커뮤니케이션](/docs/business/thinking-tools/04-communication/#situation-behavior-impact) |
