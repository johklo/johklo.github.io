『Machine Learning Platform Engineering』을 읽으며 **모델을 만드는 일과 모델이 계속 잘 작동하도록 만드는 일의 차이**를 정리하는 북클럽 독서노트다.

저자는 Benjamin Tan Wei Hao, Shanoop Padmanabhan, Varun Mallya이며, 출판사는 Manning이다. **챕터당 글 하나를 두고, 글 안에서는 원문의 절 번호를 따라 정리한다. 현재는 전체 구성 소개와 1~3장만 공개한다.** 4~13장 원고는 초안으로 보관한다.

시작점은 [00. 책의 구성과 북클럽 읽기 지도](00-overview/)다. 각 글에는 책을 읽고 이해한 내용, 추가로 확인한 용어, 실무에서 확인할 질문과 북클럽에서 논의할 쟁점을 남긴다.

도구 사용법보다 **MLOps 엔지니어로 설계·구현·운영하고, 컨설팅에서 현황을 진단해 근거 있는 개선안을 제시하는 데 필요한 판단**에 초점을 둔다. 선택의 조건, 실패 대응, 검증 증거와 고객에게 남길 산출물을 함께 정리한다.

원문의 코드와 도표를 전재하거나 문단별로 번역한 자료는 아니다. **핵심 논점을 내 언어로 정리한 독서노트**다. 실습에서는 책과 [저자들의 코드 저장소](https://github.com/practical-mlops)를 함께 참고한다.

**실무·컨설팅 메모는 원문의 논점에서 확장한 내 적용 기준**이다. 저자의 주장이나 구현과 구분한다. 실제 적용 기준은 고객의 업무 위험·규제·운영 여건에 맞춰 합의해야 한다. 글을 읽는 것과 운영 역량을 입증하는 것도 별개다.

도식은 개념과 책임의 관계를 정리하기 위해 새로 그린다. 용어를 추가 조사한 경우에는 해당 글에 공식 문서 등 확인한 출처를 남긴다.
