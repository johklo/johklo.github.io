한 번의 모델 호출에서 시작해 문서 요약과 질의응답을 만들고, 도구를 사용하는 에이전트로 확장하는 책입니다. 검색과 생성의 차이, 그래프 상태가 전달되는 방식, 모델의 판단과 실제 도구 실행의 경계를 중심으로 정리합니다.

각 장은 쉬운 비유로 개념을 잡고, 직접 실행한 예제의 중간 결과와 실패 지점을 함께 살펴보는 순서로 구성했습니다. 공통 실행 환경은 첫 글에 모았습니다.

검색, 에이전트, MCP를 운영하는 전체 구조는 가상 서점 Bookway의 [LLMOps 가이드](/docs/tech/ops/llmops/)에 연결했습니다.
