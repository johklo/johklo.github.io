『Machine Learning Platform Engineering』을 함께 읽고, **모델을 만드는 일과 모델이 계속 잘 작동하도록 만드는 일의 차이**를 정리하는 북클럽 시리즈입니다.

저자는 Benjamin Tan Wei Hao, Shanoop Padmanabhan, Varun Mallya이며, 출판사는 Manning입니다. 제공된 EPUB의 목차를 기준으로 **전체 구성 소개 1편과 13개 챕터별 독서 노트**를 읽는 순서대로 배치했습니다.

처음이라면 [00. 책의 구성과 북클럽 읽기 지도](00-overview/)부터 시작해 주세요. 각 글은 쉬운 비유에서 출발해 핵심 개념, 설계 판단, 직접 해볼 활동, 토론 질문으로 이어집니다.

목표는 책의 도구를 설명하는 데서 끝나지 않습니다. **MLOps 엔지니어로 설계·구현·운영하고, 컨설팅에서 현황을 진단해 근거 있는 개선안을 제시하는 데 필요한 판단**까지 연습합니다. 각 챕터의 실무·컨설팅 절에서는 선택의 조건, 실패 대응, 검증 증거와 고객에게 남길 산출물을 다룹니다.

원문의 코드와 도표를 전재하거나 문단별로 번역한 자료는 아닙니다. **핵심 논점을 제 말로 정리한 독서 노트**이며, 적용 예시와 토론 활동은 북클럽을 위해 재구성했습니다. 실습은 책과 [저자들의 코드 저장소](https://github.com/practical-mlops)를 함께 보면서 진행합니다.

**실무·컨설팅 절은 원문 논점을 바탕으로 확장한 적용 가이드**입니다. 책의 구현이나 저자의 주장과 동일한 것으로 읽지 않습니다. 예시 기준은 고객의 업무 위험·규제·운영 여건에 맞게 합의해야 하며, 글을 읽는 것만으로 프로덕션 운영 역량이 검증되지는 않습니다.

각 글의 도식은 원문 그림의 복제가 아니라, 해당 장의 책임과 데이터 흐름을 이해하기 위해 새로 그린 개념도입니다.
