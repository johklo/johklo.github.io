한 번의 모델 호출로 시작한 프로그램이 문서 요약, 검색 기반 질의응답, 도구 에이전트로 확장되는 과정을 다루는 책이다. 웹 리서치 엔진과 여행 도우미를 따라가며, 기존 방식의 한계가 다음 설계로 어떻게 이어지는지 읽는다.

각 글은 챕터의 중심 문제에서 출발해 개념과 구현을 연결하고, 작은 실습으로 그 설계가 해결하는 범위와 남는 한계를 확인한다. 전체 흐름과 공통 실행 환경은 [책의 구성](00-overview/)에 모았다.

검색, 에이전트, MCP 운영 구조는 가상 서점 Bookway의 [LLMOps 가이드](/docs/tech/ops/llmops/)에 연결했다.
